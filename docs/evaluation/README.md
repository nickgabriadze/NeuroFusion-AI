# Evaluation & trustworthiness

## 1. Core metrics

| Task | Primary metrics | Secondary analyses |
|---|---|---|
| CN/MCI/AD | Macro-F1, class sensitivity, one-vs-rest AUROC | confusion matrix, calibration |
| MCI→AD | AUROC, AUPRC, sensitivity, specificity | Brier score, calibration, PPV/NPV |

## 2. Calibration and uncertainty

The project treats calibration and uncertainty as core evaluation outputs, not afterthoughts.

Candidate approaches include:

- Platt scaling
- isotonic regression
- temperature scaling

Uncertainty should be explicit and experimentally justified.

## 3. Explainability

Interpretability tools include:

- SHAP for tree-based models
- integrated gradients or ablation for neural models
- modality contribution analysis via performance delta

## 4. Leakage prevention checklist

- [x] split at participant level
- [x] fit preprocessing within training folds only
- [ ] fit feature selection inside training folds only
- [ ] fit calibration on validation data only
- [ ] enforce progression time cut-offs programmatically
- [x] use the same held-out participants for comparisons

## 5. Bootstrap confidence intervals

Confidence intervals should be generated by resampling participants, not rows.
